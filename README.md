# Git 远程仓库协作总结

## 本地仓库和远程仓库分别有什么作用？
本地仓库主要用于在自己的电脑上编写、修改和提交代码，可以随时记录版本历史。远程仓库主要用于备份、本地与其他设备之间的同步、团队共享，以及在网页端查看文件和提交记录。

## 为什么需要把本地提交同步到远程仓库？
因为只保存在本地的提交无法在其他设备或远程平台上查看，也不方便协作和备份。同步到远程仓库后，项目内容和提交历史会更加安全，也更方便共享和检查。

## 远程平台直接修改文件后，本地仓库为什么需要同步远程变化？
因为远程平台上的修改会形成新的提交记录，如果本地不及时同步，就会和远程仓库内容不一致。拉取远程变化后，本地文件和提交历史才能与远程保持一致。

## 如果本地和远程同时修改了同一个文件，可能会发生什么？
如果本地和远程同时修改了同一个文件，可能会在拉取或合并时产生冲突。Git 无法自动判断应该保留哪一部分内容时，就需要开发者手动解决冲突。

## 本次任务中最后一次提交为什么要只包含 README.md 的回答内容？
因为最后一次提交的目的是单独整理任务总结和问题回答。把 README.md 单独提交，可以让提交历史更清楚，老师也能直接看出最后一次提交是对任务总结的补充，而不是和其他文件修改混在一起。
